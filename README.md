# 🎭 Abdullah Al Omar - Senior SQA Engineer & Automation Lead Portfolio

Welcome to the official repository for the personal portfolio website of **Abdullah Al Omar**, a Senior Software Quality Assurance Engineer and Test Automation Specialist. Built with a highly interactive, modern, and professional aesthetic, this web application showcases advanced testing workflows, interactive SQA sandboxes, technical competencies, and case studies.

---

## 🚀 Key Features

This portfolio is not just a static CV; it includes an **Interactive Quality Engineering Studio** (Sandbox) where visitors can experience QA tooling live:

*   **⚡ Live Test Suite Runner**: Simulates running automated test suites (Playwright/Selenium) with real-time log streaming, progress bars, and execution statistics.
*   **🌐 API Assertion Tester**: Allows live HTTP requests and schema validation assertions directly from the browser.
*   **🐞 Bug Board & RCA**: Displays defect reports with detailed Root Cause Analysis (RCA), severity levels, and logs.
*   **🧮 QA ROI Calculator**: Estimates financial savings and ROI from automating manual test suites.
*   **🎨 Premium Glassmorphism UI**: Beautiful dark and light modes, responsive sticky layout, customized typography, and micro-interactions.

## 🛠️ Technology Stack

*   **Framework**: [Next.js 14](https://nextjs.org/) (App Router)

*   **Styling**: [TailwindCSS](https://tailwindcss.com/)
*   **Animations**: [Framer Motion](https://www.framer.com/motion/)
*   **Icons**: [Lucide React](https://lucide.dev/)
*   **Effects**: [Canvas Confetti](https://github.com/catdad/canvas-confetti)

## 💻 Getting Started

Follow these instructions to set up the project locally:

### Prerequisites

Ensure you have **Node.js** (v18.x or higher) and **npm** (v9.x or higher) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/sqa-portfolio.git
   cd sqa-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```text
   http://localhost:3000
   ```

## 🏗️ Production Build & Deployment

To build the application for production:

```bash
npm run build
```

To run the production bundle locally:

```bash
npm run start
```
